# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in `@driveloader/react`, please do NOT open a public GitHub issue.

Please report security issues directly via email to the maintainers or via GitHub Security Advisories. Reports will be acknowledged within 24 hours and patches released promptly.
